# 实验二　搜索算法

用 A* 求解四邻域迷宫与加权路径，用 Minimax 和 Alpha-Beta 求解博弈树与宝藏争夺。四道原题和题一的两张补充地图都在 `cases.py`，无需下载数据。

## 运行

从仓库根目录进入 `lab2`。使用 Python 3.12 或以上版本，绘图依赖 Pillow。以下命令以 Windows PowerShell 为例，直接调用虚拟环境中的 Python，无需激活环境。

```powershell
cd lab2
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

macOS / Linux 对应命令：

```sh
cd lab2
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

`main.py` 自动创建 `results/`，重复运行会更新同名文件。五张图位于 `results/figures/`，CSV 和 JSON 位于 `results/`。没有中文字体时，图中使用英文标注。

单独检查原题时，可在同一环境运行 `python main.py --task 1`（将 1 换为 2、3 或 4）。题四可加 `--depth 2` 或 `--depth 4`，输出 `best_target` 和 `best_value`。此处的 `python` 指上方创建的虚拟环境解释器。加 `--input 文件名.json` 可替换题目输入：题一、二使用 `start`、`goal`、`map`，题三接受要求文档中的 `tree_structure`，题四字段见 `cases.py` 的 `TREASURE`。

`pathfinding.py` 实现 A*，按右、下、左、上生成邻居，同优先级按入队序处理。`game_search.py` 实现博弈搜索，最优首步并列时取编号小者，根处必要的重新搜索计入节点数。程序用 `reference.py` 中独立实现的 Dijkstra 核对路径代价和距离矩阵，再以收益递推核对题四的首步及收益差。

## 表 4 的计时口径

距离矩阵只计算一次。每种方法在每个深度先预热一次，再独立测 7 组，每组连续搜索 1000 次。每组总时间除以 1000 得到单次均值（毫秒），取 7 个均值的中位数。表 4 每格为「中位数〔最小值～最大值〕」，均取自同一方法、同一深度的七组测量，单位为毫秒。计时包括行动排序和并列复查；距离预计算、额外的分支记录、写文件和绘图在计时区间之外。耗时减少比例为 `100 × (固定序中位数 − 收益序中位数) / 固定序中位数`，以未舍入的数值计算。

节点数、路径和收益差可逐项复现。单次搜索耗时很短，机器、Python 版本和系统负载均会影响结果，减少比例甚至可能变号。报告中的 −1.40%、5.66%、7.56% 来自下列原始测量；每次运行都会重新计时。
